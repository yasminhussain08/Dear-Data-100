# Dear-Data-100 : ReadME File
1) Research Question:
   Based on 100 samples, how can observations of hijabs be turned into visual data?

2) Project Overview:
  For this project, I explored the different hijab styles that I came across. Through collecting 100 data observations, I am going to turn my dataset into a visual sketch that explores patterns and differences in hijabs, inspired by Dear Data.

3) Project Objectives:
   - To collect 100 observations of hijabs in everyday life.
   - Record their colours, styles, patterns, materials, dates, and locations.
   - Identify the patterns and similarities in data.
   - Create a visual sketch of this data using Processing.

4) Data Collection Method:
   I will collect 100 samples of data using my observations in everyday environments. Each of these observations will be recorded in a table in Excel, using an index, date, colour, style, pattern, material, and location. The samples reflect the hijabs that I encounter when I collect the data.

   
5) Data Analysis:
   Once all my samples have been collected, I need to compare the categories to identify the data that I have recoded. I will explore how the characteristics of the data collected varies across different locations. This analysis lets me identify what aspects of the data to highlight in my final sketch.
   
7) Data Visualisation - Processing.org
   I plan on using Processing.org to turn the data that I have collected into a visual sketch, inspired by the Dear Data project. Each sample will contribute to my final sketch using a range of different colours, shapes, patterns and other visual elements.
The final outcome will transform our observations into a visual sketch. This presents everyday hijab styles as more than just numbers in a table.
